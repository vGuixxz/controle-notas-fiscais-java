# Controle de Notas Fiscais

Sistema em Java e MySQL para cadastro e conferência de notas fiscais,
inspirado na rotina de recebimento de mercadorias.

## Status
Em desenvolvimento.

## Objetivo
Cadastrar notas fiscais e seus itens, e conferir o que foi recebido
contra o que a nota informa, apontando divergências.

## Tecnologias
- Java
- MySQL
- JDBC
- Maven
- Git/GitHub

## Funcionalidades planejadas
- [ ] Cadastro de notas fiscais
- [ ] Cadastro de itens da nota
- [ ] Conferência de mercadorias e relatório de divergências
- [ ] Consulta e listagem de notas
